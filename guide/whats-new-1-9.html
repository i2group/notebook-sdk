    What's new in version 1.9

    Version 1.9 of the i2 Notebook API adds support for brush sets, granular property-level change tracking in chart change events, improved mutation APIs that return promises, new line and border styling options, local-only element style editing, and several smaller additions and deprecations.

    • Brush Sets API — Create and manage brush sets to apply color-based highlighting to chart elements with discrete or gradient color ranges.
    • Property-level change tracking — Chart change events now include granular details about which properties, notes, and source references changed within each record.
    • Async mutations — runTrackedMutations and runUntrackedMutations now return promises for better control flow in long-running operations.
    • Direct chart and view access — Access the chart and view objects directly from the root API for simplified data queries and operations.
    • Line and border styling — New lineStyle and borderStyle properties on nodes, edges, and groups with support for solid, dashed, dotted, dash-dot, and dash-dot-dot styles.
    • Local-only style editing — Edit element appearance locally without persisting changes to the server, useful for transient UI state.
    • Group layout commands — New layout commands that work within groups or on selections.

    app namespace

    IApplication

    • brushSets — access to the brush sets manager for creating and managing brush sets.
    • valueFactory — factory for creating values used in the API, including brush color ranges.

    ITrackedMutations / IUntrackedMutations

    • runTrackedMutations and runUntrackedMutations now return a promise of the mutation response. The callback API is deprecated.
    • setProgress — new mutation API for setting progress during long-running operations.
    • IUntrackedMutations provides methods (editNode, editEdge, editEdgeSummary, editNodeGroup) for editing element appearance locally without persisting to the server. Useful for temporary styling, transient highlights, or UI state visualization. Changes are applied immediately to the chart UI but are lost on page reload.

    IValueFactory

    • createBrushColorRange — create discrete or continuous (gradient) color ranges for brush sets.

    PropertiesSpecifier / EditPropertiesSpecifier

    • New common specifier types for record properties in mutation APIs.

    IApplicationContents

    • chart and view — direct access to chart and view on root APIs.

    chart namespace

    IChartChangeMinor

    • recordChanges — optional field providing granular change details for each changed record, enabling plug-ins to determine exactly which properties, notes, and source references changed.

    IRecordChanges

    • New interface providing detailed change information for properties, notes, and source references within records; see IRecordChanges.

    ChartEventMap

    • brushsetchange — new event fired when a brush set changes.

    visual namespace

    INodeStyle / IEdgeStyle / INodeGroupStyle

    • lineStyle — line style property added to edge visual styles.
    • borderStyle — border style property added to node and group visual styles.
    • Added LineStyle type with support for solid, dashed, dotted, dash-dot, and dash-dot-dot styles.
    • Updated border color, border width and border style valid options.

    schema namespace

    • New type that allows schema types to be identified by either ChartItemTypeId or AnalyzeItemTypeId.

    data namespace

    IBaseChartData

    • New base interface for common chart data properties; see IBaseChartData.

    Deprecations

    • Callback API for mutations: The callback parameter on runTrackedMutations and runUntrackedMutations is deprecated. Use the returned promise instead.
    • RecordPropertiesSpecifier / EditRecordPropertiesSpecifier: Deprecated in favor of PropertiesSpecifier and EditPropertiesSpecifier.
    • IChartChangeMajor: The distinction between major and minor chart changes has been removed. All chart change events are now of type 'minor'. Use IChartChange instead. This interface will be removed in the next major release.
    • IGroupBase.isCollapsed: Deprecated in favor of IGroup.type.
    • app.ThemeName and app.ITheme.themeName: Deprecated.
